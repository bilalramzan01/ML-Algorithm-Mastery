# 🚀 ML-Algorithm-Mastery

Welcome to **ML-Algorithm-Mastery**! This repository serves as a comprehensive, step-by-step guide and coding portfolio for learning, implementing, and understanding machine learning algorithms from the ground up. 

Whether you are building models from scratch using NumPy or deploying them with Scikit-Learn, this repo is structured to take you from core fundamentals to advanced predictive modeling.

---

## 🗺️ Learning Roadmap & Curriculum

The repository is organized into sequential modules. Each module contains theory notes, mathematical intuition, and hands-on Jupyter Notebook implementations.

### Module 1: Data Preprocessing & Exploratory Data Analysis (EDA)
* **Data Cleaning & Handling Missing Values**: Imputation strategies, outlier detection.
* **Feature Scaling**: Min-Max Scaling vs. Z-score Standardization.
* **Encoding Categorical Data**: Label Encoding, One-Hot Encoding, and Target Encoding.
* **Dimensionality Reduction**: Principal Component Analysis (PCA) and t-SNE.

### Module 2: Supervised Learning - Regression (Continuous Targets)
* **Simple & Multiple Linear Regression**: Ordinary Least Squares (OLS) derivation and implementation.
* **Polynomial Regression**: Capturing non-linear relationships.
* **Regularization Techniques**: Ridge ($L_2$), Lasso ($L_1$), and ElasticNet regression to prevent overfitting.

### Module 3: Supervised Learning - Classification (Discrete Targets)
* **Logistic Regression**: Sigmoid function, log-loss, and decision boundaries.
* **K-Nearest Neighbors (KNN)**: Distance metrics (Euclidean, Manhattan) and the curse of dimensionality.
* **Support Vector Machines (SVM)**: Maximum margin classifiers, hyperplanes, and the Kernel Trick.
* **Naive Bayes Classifier**: Bayes theorem and probability distributions for text/tabular data.

### Module 4: Decision Trees & Ensemble Methods
* **Decision Trees**: Information Gain, Gini Impurity, entropy, and pruning strategies.
* **Bagging**: Random Forests and Extra Trees.
* **Boosting**: Gradient Boosting Machines (GBM), XGBoost, LightGBM, and AdaBoost.
* **Voting & Stacking**: Combining diverse models for robust performance.

### Module 5: Unsupervised Learning (Pattern Discovery)
* **Clustering**: K-Means, Hierarchical Clustering, and DBSCAN.
* **Anomaly Detection**: Isolation Forests and One-Class SVMs.

### Module 6: Introduction to Neural Networks & Deep Learning
* **Perceptrons & Multi-Layer Perceptrons (MLP)**.
* **Activation Functions**: ReLU, Sigmoid, Tanh, Softmax.
* **Optimization**: Gradient Descent, Backpropagation, and Adam optimizer.
